# Pipa 交互与快捷键体验规划

> 本文是体验研究与验收记录；应用内快捷键设置和当前源码是现行行为的最终依据。

## 目标

Pipa 面向需要频繁切换连接、查询和表数据的开发者。体验方向保持“紧凑、可扫描、操作可撤回”：新用户依靠可见按钮完成任务，熟练用户再自然过渡到快捷键，不让任何关键功能只存在于右键菜单或记忆中。

## 统一交互模型

所有对象遵循同一套动作语义，减少用户在连接、数据表、标签页和数据行之间重新学习：

| 动作 | 统一语义 | 当前/规划行为 |
| --- | --- | --- |
| 单击 | 选中并显示当前上下文 | 连接、表、数据行统一选中 |
| 双击 | 打开或进入编辑 | 连接展开、表打开、单元格编辑 |
| 右键 / `Shift+F10` | 次要和危险操作 | 连接删除；后续增加重命名、复制配置 |
| `Enter` | 确认或打开当前焦点对象 | 单元格确认已支持；连接/表打开列入 P1 |
| `Escape` | 退出当前最小操作层级 | 取消编辑、关闭菜单/弹窗、清除选择 |
| `Delete` / `Backspace` | 只处理已明确选中的对象 | 必须经过确认；不直接执行生产删除 |

## 快捷键规范

### 全局与工作区

| 快捷键 | 行为 | 设计说明 |
| --- | --- | --- |
| `Cmd/Ctrl+T` | 在当前 MySQL 连接新建 SQL | 保持现有行为，按钮和提示同时可见 |
| `Cmd/Ctrl+W` | 关闭当前工作区标签 | P1；有未提交表变更时先确认 |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | 前后切换工作区 | P1；符合浏览器和 IDE 习惯 |
| `Cmd/Ctrl+Shift+P` | 打开命令面板 | P2；用于发现全部命令及其快捷键 |
| `Cmd/Ctrl+F` | 搜索当前焦点区域 | P1；编辑器查 SQL，连接树查表，数据网格查值 |
| `Escape` | 逐层退出菜单、弹窗、编辑或选择 | 始终只退出最内层状态，不改变数据 |

### SQL 查询

| 快捷键 | 行为 | 设计说明 |
| --- | --- | --- |
| `Cmd/Ctrl+Enter` | 执行选中 SQL；无选区时执行当前语句 | P1 主快捷键，符合多数数据库工具 |
| `Cmd/Ctrl+R` | 同上 | 保留一个版本作为兼容别名，并在提示中引导迁移 |
| `Cmd/Ctrl+.` | 取消当前查询 | P1；运行时工具栏必须同时显示“取消” |
| `Cmd/Ctrl+L` | 聚焦并选中当前 SQL | P2；仅编辑器聚焦时生效，避免全局冲突 |

### 表数据工作台

| 快捷键 | 行为 | 设计说明 |
| --- | --- | --- |
| `Cmd/Ctrl+A` | 选择当前页全部行 | 保持现有作用域，并明确显示“当前页” |
| `Space` | 切换焦点行选择 | P1；便于纯键盘批量操作 |
| `Shift+↑/↓` | 扩展连续行选择 | P1；与文件管理器一致 |
| `Enter` | 确认单元格编辑 | 已支持，不自动提交到数据库 |
| `Escape` | 放弃当前单元格编辑；再次按下清除行选择 | P1 统一逐层退出 |
| `Cmd/Ctrl+S` | 打开变更预览并确认提交 | P1；生产环境仍需要二次确认 |

`Cmd/Ctrl+A` 永远只选择当前已加载页，不能暗示跨分页全选。状态栏应显示“已选择 50 / 50 行（当前页）”，跨页批量操作未来需要单独的显式入口和服务端条件预览。

## 反馈与安全设计

1. 所有数据库修改先进入本地变更集，工具栏持续显示修改数量，提交前展示最终 SQL。
2. 成功操作使用短时状态提示；失败提示保留在操作附近，并提供重试，不让错误只闪现一次。
3. 删除连接必须显示名称、类型、地址和影响范围。生产连接使用更明确的危险按钮文案。
4. 查询运行期间锁定会破坏上下文的动作；用户可以先取消查询，再删除连接或关闭标签。
5. 焦点必须可见。快捷键只作用于当前焦点区域，尤其是搜索、全选和删除。
6. 右键菜单只承载次要操作；常用动作仍提供可见按钮或悬浮提示，避免隐藏功能成为唯一入口。

## 分阶段落地

### P0：当前版本

- 连接右键删除，支持 `Shift+F10`、二次确认、错误保留和成功提示。
- 删除操作原子清理连接、凭据、相关查询标签与查询历史。
- 单击选中、双击打开/编辑、右键次要操作的语义统一。
- 表格 `Cmd/Ctrl+A` 限定为当前页，输入框内保留原生文本全选。

### P1：低成本一致性

- 增加 `Cmd/Ctrl+Enter` 执行 SQL、`Cmd/Ctrl+W` 关闭标签、`Ctrl+Tab` 切换标签。
- 连接和表树支持方向键、`Enter` 打开、`Escape` 收起。
- 表格支持 `Space` 选择行、`Shift+↑/↓` 连续选择和明确的当前页选择计数。
- 所有按钮提示统一显示命令名称与快捷键，原生菜单与页面提示保持一致。
- 标签、连接和表存在未提交状态时显示圆点标记；关闭前仅在确有数据损失时确认。

### P2：可发现性与效率

- 提供 `Cmd/Ctrl+Shift+P` 命令面板，搜索连接、表、工作区和全部命令。
- 增加“最近打开”与模糊搜索，减少在大型连接树中定位对象的成本。
- 右键菜单补充重命名、复制连接配置、重新连接，但保持删除在菜单底部独立分组。
- 提供一页可搜索的快捷键帮助，不在初次启动时弹出强制教学。

## 验收标准

- 不使用快捷键的新用户也能完成添加连接、打开表、编辑数据、提交和删除连接。
- 任何永久删除都至少有一次包含真实影响范围的确认。
- 同一快捷键不会在相同焦点范围内产生两种含义。
- 菜单、弹窗和编辑状态都能使用 `Escape` 退出，键盘焦点不会丢失。
- 5 个以上连接、20 个以上工作区标签和 1000 张表时，常用对象仍能在三次动作内定位。
- 通过 5 名目标用户的任务测试：首次打开表不超过 30 秒，第二次完成同任务不超过 10 秒，危险操作误触为 0。
